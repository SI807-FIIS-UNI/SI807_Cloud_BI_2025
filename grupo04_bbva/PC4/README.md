# 📁 PC4 – Lógica de Evidencias y Entregables
Este repositorio contiene las evidencias solicitadas para la **PC4**.
## 📂 Estructura del repositorio
```
PC4/
│
├── 1_Arquitectura Avanzada en la Nube
│   └── Documentación de la arquitectura lógica y física en Azure:
│       Diagrama, servicios usados, flujos end-to-end, escalabilidad,alta disponibilidad, DR y justificación de diseño.  
│
├── 2_Ambiente Azure
│   └── Paso a paso de la creación del ambiente en Azure: recursos, scripts de despliegue, configuración de red, seguridad, Data Lake y ETL en la nube.
│
├── 3_Funcionamiento del Dashboard
│   └── Explicación funcional del dashboard en React + Flask: KPIs, consultas SQL, validación de datos, navegación y demo del sistema.
│
├── 4_Costos
│   └── Matriz de costos del entorno Azure, proyección a 6 meses, estrategias de optimización y comparación TCO on-premise vs. cloud.
│
├── 5_Archivos utilizados
│   └── Datasets, scripts y notebooks utilizados: CSV de entrada, diccionario de datos, código de carga/ETL y consultas SQL finales.
│
└── README.md
```
